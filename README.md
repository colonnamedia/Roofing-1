# Iron Ridge Roofing Co. — FireWorks Storefront Demo

A premium three-page residential roofing website built as a reusable FireWorks storefront system for Pittsburgh-area contractors.

## Pages

- Home: conversion-focused hero, priority storm/leak form, services, process, financing, claim support, and sample reviews.
- Services: roof replacement, repairs, storm damage, gutters, and repair-vs-replace guidance.
- Inspection: detailed free-inspection request form and safety guidance.

## Local development

```bash
npm run check
npm run build
npx serve dist
```

## Launch requirements

This repository is a fictional demo. Before launching it for a real company:

1. Replace the demo business name, phone number, service area, claims, and sample reviews.
2. Connect both forms to an approved email, CRM, or dispatch destination with spam protection.
3. Add real licensing, insurance, warranty, financing, and manufacturer-certification details only after verification.
4. Replace or license all photography as appropriate.
5. Update canonical URLs, structured data, Open Graph data, sitemap, and contact information.
6. Remove `noindex, nofollow` and change `robots.txt` only after final approval.
